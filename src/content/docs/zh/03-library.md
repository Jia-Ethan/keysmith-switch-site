## 新建提示词

- **快速部署**：粘贴正文、填标题，生成预览后直接部署。也可以点「仅保存到库」。
- **拖入文件**：在快速部署的编辑区拖入 `.md`、`.markdown` 或 `.txt` 文件（最大 1 MB），内容会填进编辑器。

标题会出现在列表、命令面板和部署计划里，起一个你一眼能认出来的名字。

## 搜索、标签与排序

列表上方的搜索框会匹配标题、正文和标签。标签按钮可以只看某一类；排序可以选「最近使用」「最近更新」「标题」或「创建时间」。

## 编辑与历史

点开一条提示词可以查看全文、编辑和查看编辑历史。编辑历史里可以比较两个版本的差异，并恢复到某个旧版本。

编辑正在部署中的提示词时要注意：**保存只改库里的内容，要重新部署一次，修改才会在 Agent 里生效**。保存后页面会提醒你。

## 右键菜单

在提示词卡片上右键（或点详情页的「⋯」），可以打开、编辑、部署、复制、复制到其他工具，或删除。

- 正在生效的提示词不能直接删除，要先停用。
- 拓展包里的提示词不显示正文，只能部署和删除。

## 收下机器上已有的提示词

如果某个 Agent 里已经有一条提示词在生效（比如你之前用命令行装过 Keysmith），但它不在库里，列表顶部会出现一张 **现在正在用的提示词** 卡片。点 **收入库并编辑**，它就成为库里的一条普通提示词，可以编辑，也会保留历史版本。

如果 Switch 读不出那段正文，会请你手动粘贴进来。

## 复制到其他 Agent

同一段规则想给几个 Agent 都用，在卡片的右键菜单里选「复制到其他工具」即可。复制出来的是独立的一条，之后分别修改互不影响。

## 命令面板

按 <kbd>⌘</kbd> <kbd>K</kbd>（Windows 上是 <kbd>Ctrl</kbd> <kbd>K</kbd>）打开命令面板：

- 输入 Agent 名字，回车切换过去；
- 输入提示词标题，回车直接生成这条提示词的部署计划；
- 「新建提示词并部署到…」、拓展、输入替换、设置也都在这里。
