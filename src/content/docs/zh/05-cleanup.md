## 什么时候用清理

- 日常使用 Keysmith 切换或部署提示词**不会**动到你的会话历史、记忆、skills 或登录状态。
- 部署被漂移拦住、有过期部署记录需要重置时，直接用默认勾选的「Keysmith 提示词部署与残留」即可，既不碰个人数据，也不要求退出 Agent。
- 需要重装或深度整理某个 Agent 时，再按需勾选指令文件、记忆文件夹、自定义扩展、会话历史或登录/缓存。

## 清理会做什么

点 Agent 页面顶部的 **清理**，弹窗顶部会先实时列出**本次保持不变的个人资产**，下方将可选项拆成两个独立区域：

### 可回滚（清理前自动保存到本地「设置 → 版本」）

1. **Keysmith 提示词部署与残留**（默认唯一勾选）：停用当前部署并清理 Keysmith 自身的 manifest / wrapper 等残留，不影响个人数据，也无需退出 Agent。
2. **用户级指令文件**（默认不勾选）：如 Claude Code 的 `~/.claude/CLAUDE.md`、Codex 的 `~/.codex/AGENTS.md` 等。勾选后需额外确认，清空或移走前原样字节保存。
3. **Agent 记忆文件夹**（默认不勾选）：如 `~/.codex/memories`、`.grok/memory*`、`.zcode/cli/memories`。采用同卷**整体移动（rename）**进版本，不复制不删除；需先退出对应 Agent。
4. **自定义配置与扩展（Skills / Rules / Agents）**（默认不勾选）：`skills`、`rules`、`agents`、`commands`、`hooks`、`output-styles` 等纯扩展与规则目录。同卷整体移入版本，**不碰登录凭证，也不断开输入替换**。
5. **会话历史与对话记录**（默认不勾选）：历史对话、会话目录与状态数据库（如 `.claude/projects`、`.codex/sessions`、`state_5.sqlite`、`.grok/worktrees.db` 及 SQLite `-wal`/`-shm` 附属文件）。采用同卷**整组原子移动**进本机版本快照，误清也可在「设置 → 版本」一键完整恢复；需先退出对应 Agent。

### 永久删除（不可恢复，独立红色危险区）

- **登录凭证、含密钥配置与缓存**（默认不勾选，且必须二次勾选确认、先退出对应 Agent）：
  - 永久删除登录文件（如 `auth.json`、`.credentials.json`）、系统钥匙串登录、插件与缓存，不保存进版本。
  - 可能内嵌登录或 API Key 的配置文件（如 `.claude.json`、`settings.json`、`.grok/config.toml`、`.zcode/v2/*.json`）会先剥离所有 key、token 与账号信息并把**脱敏副本**写入版本，再删除原件；原密钥不可恢复，清理后需重新登录。如果剥离后仍检测到登录信息，清理会直接停止，不改动任何文件。

另外：

- **Codex 的 `config.toml`** 始终保留在原处：里面是你的模型、provider 和信任的项目，Codex 没有它也无法再部署。
- **`pi` 与 `DSH`** 的个人设置、凭证、会话和存储均不纳入清理表，清理时只停用 Keysmith 部署。

## 不会动的东西

- 你项目目录里的任何文件，包括 git 项目，以及 ZCode 的 `~/.zcode/workspace`；
- 你的提示词库；
- Agent 软件本身；
- 符号链接（symlink）、Windows junction 及路径中含符号链接祖先的目录，以及含有 git 项目或登录文件的文件夹，会原样留在原处。

## 版本与回滚

清理前保存的版本在 **设置 → 版本** 里，保存在 `~/.keysmith-switch/snapshots/`（纯本地文件，不在导出备份里，也不上传）。

选一个版本点 **回滚**，Switch 会先列出这次会恢复什么：

- 重新部署当时的提示词（如果当时的正文保存下来了）；
- 把用户级指令文件恢复成原样字节；
- 把记忆文件夹与会话历史（含 SQLite 主库及 `-wal`/`-shm` 附属文件，整组校验后恢复）复制放回原位，版本本身保持完整；
- 把规则、skills、命令、hooks 等扩展目录放回原位；
- 脱敏配置文件仅在当前目标位置**还没有新配置**时放回，绝不覆盖你重新登录后写下的新配置。

如果回滚会覆盖现在的内容，或补回当前原本不存在的路径，**现在的状态会先另存为一个「回滚前」版本**（并记录原本缺失的路径），所以回滚本身也能完整撤销（撤销时同样是把新增路径安全移入新的安全版本，不会直接删除）。版本快照不保存登录凭证，如果此前清理过登录，回滚后仍需重新登录。

不需要的版本可以在「版本」页单独删除（删除包含会话或记忆备份的版本时会一并释放磁盘空间）。

## 输入替换与清理

仅当你勾选了 **登录凭证、含密钥配置与缓存** 时，Switch 才会在保存脱敏配置副本前断开该 Agent 的[输入替换](/docs/rewrite/)，回滚时恢复的是你原来的上游地址，替换规则保持不变。只清理 Keysmith 部署或纯扩展目录时，不会断开输入替换。
